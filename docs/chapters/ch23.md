# 工艺与工艺参数

设计能否顺利变成产品，取决于工艺条件：芯片能造到什么程度，封装能否满足散热与引脚需求，印制板能做多细的线，良率与寿命能否保证，元件能否长期供应。本章介绍这些工艺要素及其对设计的要求。

## 半导体工艺

### 主要步骤

芯片制造的核心步骤反复循环进行：

光刻（形成图形）$\to$ 刻蚀（去除材料）$\to$ 掺杂（注入杂质）$\to$ 薄膜（生长绝缘层或金属层）

以上循环重复数十次到上百次，逐层构建出晶体管与互连结构。其中光刻可细分为五步：涂胶、经掩膜版曝光、显影、刻蚀或注入、去胶。掩膜版是每一层图形的模板，一套工艺需要数十层掩膜，层与层之间必须套刻对准。

### 关键参数

特征尺寸（工艺节点）与晶圆尺寸是最重要的两个参数。工艺节点越小，晶体管越快、单管开关功耗越低，但设计与制造成本急剧上升；晶圆尺寸（主流为 $300\,\mathrm{mm}$）越大，单片可产出的芯片越多、单位成本越低。模拟电路和功率器件常使用较成熟的节点：成本低、耐压好、良率高。良率是合格芯片数与总芯片数之比，取决于工艺成熟度、缺陷密度与芯片面积——面积越大、缺陷越多，良率越低，这是大芯片成本高的又一原因。按常用的泊松模型，良率可估算为 $Y=e^{-AD}$，其中 $A$ 为芯片面积、$D$ 为单位面积缺陷数（该式适用于缺陷密度较低的粗略估算）。选择原则是适合产品需求，而不是盲目追求先进：工艺节点早期对应栅长或半节距，现在已是工艺代的名称，不同厂家的“同节点”参数并不相同；$300\,\mathrm{mm}$ 晶圆的面积约为 $200\,\mathrm{mm}$ 的 2.25 倍，这是大晶圆降低单位成本的算术来源。代工厂以设计规则与 PDK 的形式发布工艺参数，设计必须按其进行。

!!! example "例题"

    **例 23.1**某芯片面积 $1\,\mathrm{cm^{2}}$，缺陷密度 $0.1\,\text{个}/\mathrm{cm^{2}}$，估算良率。

    **解**：

    $$
    Y=e^{-1\times0.1}\approx90\% .
    $$

!!! example "例题"

    **例 23.2**$300\,\mathrm{mm}$ 晶圆上制造 $1\,\mathrm{cm^{2}}$ 的芯片，估算理想出芯数与按 90% 良率计算的合格数。

    **解**：晶圆面积约 $707\,\mathrm{cm^{2}}$，理想出芯数约 $707$ 颗（未计边缘损耗），合格数约 $707\times90\%\approx636$ 颗。晶圆越大、芯片越小，单位成本越低。

## 封装

### 常见封装形式

| 封装      | 特点                       | 典型用途             |
|:----------|:---------------------------|:---------------------|
| QFN       | 尺寸小，靠底部散热焊盘导热 | 消费类芯片           |
| QFP / SOP | 引脚外伸，便于焊接与检修   | 通用芯片             |
| BGA       | 球栅阵列，引脚多、密度高   | 处理器、FPGA、存储器 |
| CSP       | 接近芯片本体尺寸           | 手机、可穿戴设备     |
| TO-220 等 | 可外接散热器               | 功率器件             |

常见封装形式

### 选型与焊接

选择封装考虑四点：引脚数量是否足够、散热能力是否满足（看热阻参数）、是否便于生产与检修、高度与面积是否符合要求。数量级参照：QFP 引脚间距约 $0.4\sim0.8\,\mathrm{mm}$，BGA/CSP 球间距约 $0.5\sim1\,\mathrm{mm}$，间距越小对贴装与钢网的要求越高；散热看热阻参数 $\theta_{JA}$、$\theta_{JC}$（单位 $^\circ\mathrm{C/W}$，数值越小越容易散热，用法见第 16 章）。

焊接采用回流焊工艺，温度曲线分为预热、恒温、回流、冷却四个阶段；无铅焊料的峰值温度约为 $245\,^\circ\mathrm{C}$（有铅约 $220\,^\circ\mathrm{C}$），通孔元件则以波峰焊为主。受潮器件在焊接前需要按潮敏等级要求烘烤，否则内部水汽受热膨胀会造成封装开裂（俗称爆米花效应）。

## 印制板制程

### 主要工序

多层板的制作流程：

开料 $\to$ 内层图形 $\to$ 层压 $\to$ 钻孔 $\to$ 孔金属化（镀铜）$\to$ 外层图形 $\to$ 阻焊与丝印 $\to$ 表面处理 $\to$ 成型 $\to$ 测试

各工序的作用：内层图形是蚀刻出内层导体；层压用半固化片把多层板压合；钻孔与孔金属化实现层间互连；阻焊保护铜面、防止桥连；表面处理保证可焊性；测试检查开短路。高密度板还会采用积层与激光微孔（HDI 工艺）。

### 工艺能力

与设计直接相关的常规能力：

| 参数        | 常规能力                              | 说明                 |
|:------------|:--------------------------------------|:---------------------|
| 线宽 / 线距 | $6\,\mathrm{mil}$ / $6\,\mathrm{mil}$ | 更细需更高工艺等级   |
| 最小孔径    | $0.2\sim0.3\,\mathrm{mm}$             | 更小孔径需要激光钻孔 |
| 板厚 / 铜厚 | $1.6\,\mathrm{mm}$ / $1\,\mathrm{oz}$ | 大电流场合增加铜厚   |
| 阻抗控制    | $\pm10\%$                             | 需要与板厂确认叠层   |

常见工艺能力（普通板）

表面处理方式：喷锡成本低但表面不平整；沉金平整，适合细间距焊盘与多次回流焊；OSP 环保但保存期短。两个单位先换算：1 mil $=$ $0.0254\,\mathrm{mm}$，$6/6\,\mathrm{mil}$ 约 $0.15\,\mathrm{mm}$；1 oz 铜厚约 $35\,\mu\mathrm{m}$——大电流走线可加宽或加厚。阻抗控制 $\pm10\%$ 指板厂保证的偏差范围，更严的要求（如 $\pm5\%$）需与板厂确认叠层与公差。

高频板材按损耗水平分为普通 FR-4、中损耗、低损耗与超低损耗几类，损耗越低、价格越高。设计与下单前应先确认所用板厂的工艺能力。

## 可制造性设计

常见检查项目：

1.  线宽与线距不低于板厂能力；

2.  QFN 等的焊盘按手册适当内缩（或缩小钢网开口），防止连锡；

3.  丝印不压焊盘；

4.  过孔避开焊盘或做塞孔处理；

5.  拼板设置工艺边，连接方式（V 割、邮票孔）与生产商确认；

6.  留出基准点供贴片机定位。

使用板厂提供的在线检查工具或专用 DFM 软件，可以在下单前发现大部分问题，避免返工、降低成本。

## 可靠性与失效分析

### 常用可靠性试验

| 试验         | 内容               | 目的                     |
|:-------------|:-------------------|:-------------------------|
| 高温工作寿命 | 高温下长期通电     | 考核长期工作寿命         |
| 温度循环     | 在低温与高温间循环 | 考核焊点与材料疲劳       |
| 高温高湿     | 高温高湿环境存放   | 考核湿气腐蚀             |
| 静电放电     | 模拟静电冲击       | 考核器件耐受能力         |
| 振动与跌落   | 施加机械应力       | 考核结构强度与焊点可靠性 |

常用可靠性试验

试验的典型条件（量级）：高温工作寿命约 $125\,^\circ\mathrm{C}$、$1000\,\mathrm{h}$；温度循环在 $-40\sim125\,^\circ\mathrm{C}$ 之间；高温高湿为 $85\,^\circ\mathrm{C}$、$85\%$ RH。

### 寿命规律

焊点疲劳主要由温度循环引起：各材料的热膨胀系数不同，反复伸缩最终导致开裂。裂纹先从应力集中的角部萌生，再逐步扩展至断裂；循环寿命与温差、器件与基板的热膨胀失配程度相关。温度与寿命的定量关系（如电解电容"每升高 $10\,^\circ\mathrm{C}$ 寿命约减半"）见第 16 章。

### 失效分析

典型流程：外观检查与显微镜观察；X 射线检查内部焊点；切片观察金相组织；必要时用扫描电镜与能谱分析成分；最后通过复现试验确认原因。各手段对应看什么：X 射线看焊点与空洞，切片看金相与裂纹，能谱看元素成分。

## 成本与供应链

### 成本构成与降本顺序

产品成本由元件、印制板、贴片加工、测试、认证与管理费用构成。小批量时加工费用占比高，大批量时元件成本占主导。

降本顺序：优先选用通用元件；简化设计（减少层数、减少元件数量）；批量采购压价；最后优化工艺。还要理解一次性投入（NRE）：开模、认证、光罩、测试治具属于不论产量都要花的费用——产量越小，NRE 在单件成本中占比越高，这也是小批量产品倾向选用通用方案的原因。

### 供应链注意事项

- 关键元件保留第二供应商；

- 长交期元件提前下单锁定；

- 避免选用即将停产的型号，关注产品生命周期状态；

- 替代元件必须重新验证：引脚兼容不等于电气兼容（耐压、速度、温度等级都要核对）。温度等级指器件保证工作的环境温度范围：商用 $0\sim70\,^\circ\mathrm{C}$、工业 $-40\sim85\,^\circ\mathrm{C}$、汽车级更宽——所选等级必须覆盖产品的工作环境。
