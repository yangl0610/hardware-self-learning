# 电磁兼容

电磁兼容（EMC）研究两个问题：设备产生的干扰不超标（发射问题），以及设备在干扰环境下正常工作（抗扰问题）。本章介绍干扰的来源与传播途径、滤波、屏蔽与接地措施、印制板的电磁设计方法，以及问题定位流程。

## 干扰的三要素

任何电磁干扰问题都由三个环节构成：

干扰源 $\to$ 传播路径 $\to$ 受扰电路

解决措施是打断其中任意一个环节：减弱干扰源、切断传播路径、保护受扰电路。

常见干扰源：开关电源的开关节点、时钟电路、高速数据线、电机与继电器。常见路径：沿导线传导、空间辐射、近场耦合。

## 两个物理根源

干扰的根源是电压或电流的快速变化：

- 电压快速变化（$\mathrm{d}v/\mathrm{d}t$）：通过电场耦合与空间辐射传播；对策是减缓开关速度、加缓冲电路、缩小高压跳变点的面积；

- 电流快速变化（$\mathrm{d}i/\mathrm{d}t$）：通过磁场耦合传播，影响与回路面积成正比；对策是缩短走线、让回流紧贴去路，即缩小电流回路面积。

缩小回路面积不增加元件成本，是布局阶段的首要原则。两类耦合的显著条件不同：电场（容性）耦合在电压高、电流小的节点明显，磁场（感性）耦合在低阻抗、大电流回路明显——先判断干扰源属于哪一类，再选择对策。近场耦合随距离迅速衰减，拉开距离是成本最低的措施之一。

## 标准与认证项目

| 项目 | 内容 | 常用标准 |
|:---|:---|:---|
| 传导发射 | 电源端口干扰，$150\,\mathrm{kHz}\sim30\,\mathrm{MHz}$ | CISPR 32（原 CISPR 22） |
| 辐射发射 | 空间辐射，$30\,\mathrm{MHz}\sim1\,\mathrm{GHz}$ 以上 | CISPR 32（原 CISPR 22） |
| 传导抗扰 | 向端口注入干扰，设备不得异常 | IEC 61000-4-6 |
| 辐射抗扰 | 空间施加干扰，设备不得异常 | IEC 61000-4-3 |
| 静电放电 | 模拟人体静电放电（接触放电，电压可达数千伏） | IEC 61000-4-2 |
| 快速脉冲群 | 模拟开关动作产生的脉冲串 | IEC 61000-4-4 |
| 浪涌 | 模拟雷击或大电流切换浪涌 | IEC 61000-4-5 |

常见 EMC 测试项目

发射类要求"不干扰别人"，抗扰类要求"不被别人干扰"，两类都满足才能通过认证。

从 $30\,\mathrm{MHz}$ 起才评辐射发射，是因为小尺寸设备在更低频率上天线效率低、主要以传导发射考核。限值分等级：居住环境用的 Class B 比工业环境用的 Class A 更严；读数还与检波方式有关，准峰值检波更接近实际干扰效果，判定时按标准规定执行。

## 传导干扰与滤波

### 差模与共模

传导干扰电流分为两种：差模电流在两根导线之间往返（两线电流大小相等、方向相反）；共模电流在两根线上同向流动，经地线返回。多数设备的辐射超标与共模电流有关——连接电缆把共模电流变成了天线。

### 滤波元件

| 元件     | 抑制类型 | 说明                               |
|:---------|:---------|:-----------------------------------|
| X 电容   | 差模     | 跨接在两根电源线之间，需用安规型号 |
| 共模电感 | 共模     | 两根线并绕，对差模电流阻抗低       |
| Y 电容   | 共模     | 从电源线到地，受漏电流限制         |
| 差模电感 | 差模     | 串接在电源线上，抑制差模电流       |

常用滤波元件

滤波器应安装在接口最前端，滤波前后的走线在物理上分开，避免已滤波的线路与未滤波线路之间再次耦合。X 电容的容量在微法级，Y 电容在纳法级且受安规漏电流限制。共模电感对两条路径的作用不同：两根线的共模电流产生的磁通相加、呈现高阻抗；差模电流的磁通相消、阻抗很低——同一元件对两条路径的选择性由此而来。滤波器的效果用插入损耗（dB）表示，在 $150\,\mathrm{kHz}\sim30\,\mathrm{MHz}$ 的传导发射频段内考核。

## 屏蔽

屏蔽效果用屏蔽效能（dB）表示——有、无屏蔽时场强之比，来自反射与吸收两种机制。实际效果取决于孔与缝，而不是屏蔽体的面积：

- 缝隙：接缝应连续压紧，要求高时使用导电衬垫；

- 开孔：孔径接近四分之一波长时泄漏急剧增大，散热孔应使用多个小孔代替一个大孔；同等面积下，狭长缝隙（缝隙天线）比圆孔泄漏更严重，缝长接近半波长量级时最差——这就是盖板需要足够螺钉密度与导电衬垫的原因；

- 电缆：屏蔽层应环状接地，必要时在电缆上加磁环或共模扼流圈。

## 接地

接地是控制干扰的基本手段。要点：模拟地与数字地、功率地与信号地分开布置，再在一点相连，避免大电流的返回电流流经敏感信号的路径；地环路会像天线一样拾取磁场干扰，应避免形成大面积的接地回路；设备之间优先用屏蔽与隔离切断地环路，而不是依靠地线本身。更一般的经验：低频（兆赫以下）用单点接地，避免几路电流在公共地线上互相干扰；高频用平面或多点接地，减小回流电感——这与信号完整性章的回流路径原则同源。地环路受到的干扰电压与环路面积、磁场变化率成正比，优先的思路是切断环路（断开、隔离、改走线），而不是单纯加大地线截面。

## 印制板电磁设计

按优先级排列的常用措施：

1.  减小开关电源输入、输出和去耦电流的回路面积；

2.  保证地平面完整，避免信号跨分割布线；

3.  晶体与时钟电路远离接口和板边，下方净空并包地——晶振是持续的干扰源，其高阻节点也容易受扰，净空与包地能缩短回流路径、隔离耦合；

4.  接口防护器件（如 TVS）放在连接器附近，让干扰先经过防护再进入芯片；

5.  滤波元件紧贴接口安装；

6.  高压区与低压区分区布置：电气间隙是空间最短距离、爬电距离是沿绝缘表面的距离，两者都随工作电压与污染等级增大。

## 问题定位与整改

### 流程

1.  用近场探头配合频谱仪在板面上扫描，找到辐射最强的位置；

2.  观察干扰频率与开关频率、时钟频率的关系，判断来源；

3.  改变电缆的长度或位置，若辐射明显变化，说明共模分量占主导；

4.  按先布局、再滤波、后屏蔽的顺序处理，每次只改一处并记录频谱变化；

5.  将有效的措施固化到下一版设计规范中。

!!! example "例题"

    **例 22.1**某接口需要防止静电打坏内部芯片，TVS 管应安装在什么位置？

    **解**：安装在连接器与内部电路之间、紧靠连接器的位置，使放电电流在进入芯片之前先被引走。若装得靠里，放电电流会先经过芯片，防护失去意义。

!!! example "例题"

    **例 22.2**某设备辐射发射超标，拔掉所有外部电缆后通过。判断干扰途径，并给出两种整改措施。

    **解**：超标主要由电缆辐射贡献——电缆成为天线、由共模电流驱动，属于共模传导与辐射的混合途径。措施一：在电缆接口处加共模扼流圈或磁环，抑制共模电流；措施二：从源头减小共模电流（检查开关节点与地平面处理），或改用屏蔽电缆并保证屏蔽层环状接地。

## 电缆与天线效应

天线的辐射与接收原理见第 9 章。对电磁兼容而言，关键是：当电缆、开孔或走线的尺寸与波长可比时，它们会像天线一样辐射和接收干扰。整机辐射发射超标常由电缆引起：电缆被不对称驱动形成共模电流，整根电缆便成为一根天线。量级感受：$30\,\mathrm{MHz}\sim1\,\mathrm{GHz}$ 对应波长 $10\,\mathrm{m}\sim0.3\,\mathrm{m}$，电缆长度与之可比时辐射显著增强。针对性手段：在干扰源侧抑制共模电流（共模扼流圈、磁环）、缩短电缆、屏蔽层环状接地——与前面几节的滤波、屏蔽与布局措施互相配合。
