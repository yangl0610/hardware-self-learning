# 学习路线

以下路线是为网页版增加的阅读建议；教材正文保持原有内容。无需一次掌握所有章节，可以按当前任务逐步深入。

## 第一阶段：建立基础语言

依次阅读[微积分 I](chapters/ch01.md)、[微积分 II](chapters/ch02.md)、[常微分方程](chapters/ch03.md)和[大学物理电磁学](chapters/ch04.md)。重点理解导数、积分、电场、磁场的物理意义。

## 第二阶段：读懂电路

从[电路分析](chapters/ch05.md)出发，再学习[模拟电子技术](chapters/ch06.md)和[数字电子技术](chapters/ch08.md)。尝试把电路图中的元件与其功能逐一对应。

## 第三阶段：把设计变成实物

阅读[工艺与工艺参数](chapters/ch23.md)，认识制造和装配约束。随后学习[电力电子技术](chapters/ch13.md)、[开关电源](chapters/ch14.md)、[电源分析](chapters/ch15.md)和[热分析](chapters/ch16.md)，把功能、功率和散热放在一起考虑。

## 第四阶段：用代码连接硬件

学习[微机接口与微处理器](chapters/ch17.md)、[C 语言](chapters/ch18.md)和[C++ 语言](chapters/ch19.md)。没有编程基础时，可以先读 C 语言，再回到外设接口。

## 第五阶段：按方向进阶

| 关注的问题 | 对应章节 |
| --- | --- |
| 系统响应与闭环控制 | [自动控制原理](chapters/ch12.md)、[信号与系统](chapters/ch10.md) |
| 随机误差与数据分析 | [概率论与数理统计](chapters/ch07.md) |
| 电磁传播与通信 | [电磁场与电磁波](chapters/ch09.md)、[通信基础与原理](chapters/ch11.md) |
| 理解底层程序执行 | [汇编](chapters/ch20.md) |
| 高速信号与干扰问题 | [信号完整性分析](chapters/ch21.md)、[电磁兼容](chapters/ch22.md) |
| 多变量连续场建模 | [偏微分方程](chapters/ch24.md) |

## 每章的学习检查

1. 能否用自己的话解释本章的核心概念？
2. 能否说清主要公式的变量、单位与适用条件？
3. 能否不看答案完成一个例题？
4. 能否找到一个与真实硬件有关的应用场景？
